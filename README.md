# job-digest

IT 직무 신입 구직자를 위한 개인용 채용공고 다이제스트 도구입니다.

매일 1회 백엔드·전산·IT 직군 신입 채용공고를 조회해 마감일과 자격요건을 정리하고, 본인의 경력과 비교해 지원 여부를 판단하는 데 씁니다.

## 데이터 사용 원칙

- 비상업적 개인 용도로만 사용합니다.
- 조회한 채용공고 데이터는 저장소에 커밋하거나 외부에 공개·재배포하지 않습니다.
- API 키는 환경 변수로만 다루며 저장소에 올리지 않습니다.

## 데이터 출처

- 사람인 오픈API (승인 대기 중)
- 공공데이터포털 공공기관 채용정보 조회서비스
